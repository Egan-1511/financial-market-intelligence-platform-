# 🚀 AI-Powered Financial Market Intelligence Platform

## Overview

An end-to-end Financial Machine Learning platform designed to analyze and rank Indian stock market opportunities using Artificial Intelligence.

The platform collects historical market data, generates advanced technical indicators, incorporates market-wide intelligence from NIFTY 50 and India VIX, trains machine learning models, ranks stocks based on predicted buying opportunities, and visualizes recommendations through an interactive Streamlit dashboard.

## Running the Project

### Clone Repository

```bash
git clone https://github.com/Egan-1511/financial-market-intelligence-platform-.git
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Dashboard

```bash
streamlit run app.py
```
